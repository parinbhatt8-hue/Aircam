# AirCam
Gesture-controlled camera app (CameraX + MediaPipe Gesture Recognizer).

Gestures (hold ~1 s): Open palm = photo (3 s timer), Victory = start/stop video,
Thumb up = flip camera, Pointing up = zoom in, Closed fist = zoom out.

Build: push to GitHub, open Actions > Build APK, download the AirCam-debug-apk artifact, install it.

S Pen (hover within ~1-2 cm of the screen): click = photo, double click = video, long press = flip, hold button + move pen up/down = zoom.
